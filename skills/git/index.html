Git

✦ ✧ ✦

What it is

Version control: a complete history of every change, who made it and why, with the ability to work on something without disturbing what already works. The industry standard by a distance.

Where I use it

Everywhere, including places it was not already established — I introduced Git workflows and coding standards at Companies House, which cut duplicated work between people unknowingly solving the same problem.

The bit people get wrong

That it is for teams. The biggest beneficiary of your commit history is you in six months, trying to work out why a working query was changed and whether it is safe to change back.
