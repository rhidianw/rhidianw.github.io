SQL

✦ ✧ ✦

What it is

The language for asking questions of a relational database. You describe the answer you want — these columns, from these tables, joined this way, filtered like so — and the database works out how to fetch it. It has outlasted every technology that was going to replace it, and it will outlast the next one too.

Where I use it

Constantly, and it is the core of the job rather than a side skill. The modelling layer at Nexus Brands is SQL: the views that reconcile stock, sales and catalogue data between systems that each have their own idea of what a product is. At Companies House it was SQL against Snowflake, producing daily data quality metrics.

The bit people get wrong

That writing SQL and modelling data are the same skill. They are not. Anyone can learn joins in a weekend. Knowing which join is correct — because you understand the grain of the table and what a duplicate row actually means — takes considerably longer and matters considerably more.
