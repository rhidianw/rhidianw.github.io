Data quality

✦ ✧ ✦

What it is

Whether the data is actually right: complete, consistent, current, and meaning what people think it means. It is less a tool than a discipline, and it is usually somebody's job only after something has gone wrong.

Where I use it

An explicit role at Companies House — address data quality supporting fraud prevention — and a constant thread since. Finding the flags nobody has maintained in years, the listings attributed to the wrong account, the field that is always zero and silently trusted.

The bit people get wrong

That it is a cleanup project with an end date. It is a property of a system, not a state you reach. Without checks that run continuously, data quality decays from the moment you stop looking.
