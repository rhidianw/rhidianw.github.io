Power BI

✦ ✧ ✦

What it is

Microsoft's business intelligence tool for building dashboards and reports over a data model, aimed at letting non-technical users explore numbers without writing queries.

Where I use it

Management reporting — the presentation layer on top of the modelling work, where the measure of success is that nobody has to ask what a number means.

The bit people get wrong

That the dashboard is the deliverable. A dashboard is a window onto a data model. If the model underneath is wrong, you have built an efficient way to distribute a wrong number to more people, faster.
