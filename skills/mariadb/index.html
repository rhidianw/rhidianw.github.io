MariaDB / MySQL

✦ ✧ ✦

What it is

A relational database. MariaDB is a fork of MySQL that stayed open source after Oracle's acquisition; the two remain broadly compatible. It is the unglamorous, extremely well-understood workhorse of a great many systems.

Where I use it

It is the group reporting warehouse at Nexus Brands — every downstream sales, stock, margin and catalogue report reads from it.

The bit people get wrong

That it is interchangeable with other SQL databases. It is nearly so, until it very much is not: MariaDB has no FULL OUTER JOIN, so you emulate it with a LEFT JOIN unioned to a RIGHT JOIN. Small differences like that are exactly where a query ported from somewhere else quietly returns the wrong answer.
