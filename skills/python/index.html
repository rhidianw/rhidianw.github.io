Python

✦ ✧ ✦

What it is

A general-purpose programming language that became the default for data work, largely because it is easy to read and has a library for everything. It is not the fastest language available, which almost never matters when the slow part is the database or the network.

Where I use it

Every pipeline I own is Python. It pulls from APIs, reads flat-file drops, reshapes the results and loads them into the warehouse on a schedule. I also taught the undergraduate Python module at York for four years, which is the fastest way I know to find out whether you actually understand something.

The bit people get wrong

That the clever solution is the good one. Pipelines run unattended at three in the morning and get read a year later by someone who has never seen them. Boring, obvious code is a feature.
