Bash

✦ ✧ ✦

What it is

The shell language that glues Unix systems together. Ideal for short, practical automation: move these files, run that job, check whether something worked.

Where I use it

Scheduling and automation around the pipelines — the wiring between cron and the Python that does the actual work.

The bit people get wrong

That it scales up to real programs. Past about fifty lines, Bash becomes difficult to read and alarmingly easy to get wrong, usually around quoting and filenames with spaces. At that point it should have been Python an hour ago.
