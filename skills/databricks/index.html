Databricks

✦ ✧ ✦

What it is

A platform built around Spark that bundles notebooks, job scheduling and data storage together. It is aimed at teams doing large-scale processing and machine learning who would rather not run the cluster themselves.

Where I use it

Exposure rather than deep specialism — alongside Snowflake and Azure pipelines in the data platform work. I am comfortable in it without claiming it as a core strength, and I would rather say so than oversell it.

The bit people get wrong

That notebooks are production code. They are excellent for exploring and poor at being depended upon — no clear entry point, hidden state from cells run out of order, and a diff that tells you nothing useful.
