What it is

The Python library for working with tabular data in memory. A dataframe is a table you can filter, join, group and reshape in code, which makes it the natural bridge between a file and a database.

Where I use it

The middle of most pipelines: read the extract, reshape it, check it, write it out. Also the first thing I reach for when something looks wrong and I want to interrogate a dataset rather than guess.

The bit people get wrong

That it scales. Everything lives in memory, so there is a hard ceiling, and you tend to find it at the worst possible moment. Past that point the answer is a database or Spark, not a bigger machine.
