parquet

✦ ✧ ✦

What it is

A columnar file format for analytical data. Instead of storing row by row, it stores column by column, which compresses far better and lets a query read only the columns it actually needs.

Where I use it

The landing layer of the pipelines at Nexus Brands. Raw extracts and API pulls land as parquet before being loaded, which means a failed run can be replayed from the files rather than by hammering the source system again.

The bit people get wrong

That it is just a faster CSV. The real win is that it carries its own schema and types. A CSV will happily tell you a product code is a number, strip the leading zeros, and let you find out months later.
