C++

✦ ✧ ✦

What it is

A compiled, low-level language that gives you precise control over memory and runs about as fast as anything will. The price is that it will let you do catastrophic things without complaint.

Where I use it

My PhD. Four years of analysis pipelines in C++ and ROOT, ingesting, cleansing and analysing experimental physics data at multi-terabyte scale where the difference between fast and slow code was the difference between an answer this week and an answer next month.

The bit people get wrong

That having written C++ makes you a better programmer in other languages. What it genuinely gives you is an intuition for what the machine is actually doing — why a loop is slow, why memory layout matters — and that intuition does transfer.
