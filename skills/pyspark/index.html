PySpark

✦ ✧ ✦

What it is

The Python interface to Apache Spark, which spreads a computation across many machines so you can process datasets far too large for one. You write something that looks like ordinary dataframe code and Spark works out how to distribute it.

Where I use it

At Companies House, building automated pipelines that produced daily data quality metrics over the full register. Address data at that scale is not something you load into memory and have a look at.

The bit people get wrong

That you should reach for it by default. Spark has real overhead, and a dataset that fits comfortably on one machine will almost always be faster and simpler in plain Python. Distributed computing is a solution to a size problem, not a mark of seriousness.
