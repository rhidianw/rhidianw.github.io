Snowflake

✦ ✧ ✦

What it is

A cloud data warehouse that separates storage from compute, so you can scale the processing power up for a heavy job and back down afterwards without moving any data. You pay for what you run.

Where I use it

At Companies House, as the platform behind the automated data quality pipelines — daily metrics over address data, feeding fraud prevention and operational reporting.

The bit people get wrong

That separating storage and compute makes cost stop mattering. It makes cost *visible*, which is different. A badly written query that scans everything no longer just runs slowly, it runs slowly and bills you for the privilege.
