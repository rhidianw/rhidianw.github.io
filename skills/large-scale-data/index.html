Large-scale data

✦ ✧ ✦

What it is

The point at which data stops fitting comfortably in memory or on one machine, and the ordinary approaches stop working. Where it starts depends entirely on what you are doing with it.

Where I use it

Four years of multi-terabyte experimental datasets during the PhD, and register-scale data at Companies House. Both taught the same lesson: at scale you cannot eyeball a mistake, so the checks have to be built in.

The bit people get wrong

That it is mostly about having bigger machines. It is mostly about doing less work — reading only the columns you need, filtering before you join, and not moving data you were never going to use.
