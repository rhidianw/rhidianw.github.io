dbt

✦ ✧ ✦

What it is

A tool for managing SQL transformations as a proper software project — models in version control, dependencies resolved automatically, tests and documentation alongside the code. It brought engineering practice to warehouse SQL.

Where I use it

Familiarity with the concepts — SQL models, YAML and Jinja configuration — rather than years in production with it. Worth being precise about: the ideas behind it are how I work regardless of the tool.

The bit people get wrong

That you need dbt to work this way. The valuable parts are version control, tested transformations and explicit dependencies. dbt makes them convenient; it did not invent them.
