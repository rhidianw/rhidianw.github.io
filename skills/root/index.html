ROOT

✦ ✧ ✦

What it is

A C++ data analysis framework built at CERN for particle physics. It handles enormous datasets, histogramming and statistical fitting, and is near-universal in the field while being almost unknown outside it.

Where I use it

My PhD. Automated C++ and ROOT pipelines for ingesting, cleansing, analysing and visualising multi-terabyte experimental data.

The bit people get wrong

That domain-specific tools are a dead end on a CV. The framework does not transfer, but everything around it does: handling data far larger than memory, building reproducible analysis pipelines, and being sceptical about a result until you can trace it back to the measurement.
