Machine learning

✦ ✧ ✦

What it is

Fitting models to data so they can predict or classify without being explicitly programmed with the rules. In practice most useful work is regression, classification, clustering and forecasting rather than anything more exotic.

Where I use it

At Companies House, applying regression and time-series forecasting to predict address data trends and support operational decisions. The physics background helps here — fitting models to noisy measurements was the day job for four years.

The bit people get wrong

That it fixes bad data. A model trained on inconsistent inputs learns the inconsistency and hands it back with a confidence score attached, which is worse than no answer because it looks like an answer.
