REST APIs

✦ ✧ ✦

What it is

The common way systems expose data over HTTP — ask a URL for a thing, get structured data back, usually JSON. 'REST' describes a set of conventions that real APIs follow to wildly varying degrees.

Where I use it

Most external data arrives this way: marketplace APIs for listings, inventory, subscriptions and compliance attributes. A good deal of the work is handling pagination, rate limits and the gap between documentation and behaviour.

The bit people get wrong

That the documentation is accurate. It frequently is not. Endpoints omit the paging token the docs promise, limits are lower than stated, and fields appear and vanish. You write against what the API does, not what it says.
